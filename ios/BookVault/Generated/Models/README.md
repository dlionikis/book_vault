# Swift5 API client for BookVault

RESTful API for Book Vault audiobook library.

## Authentication

**IMPORTANT**: This API supports **dual authentication** for maximum flexibility.
All endpoints accept BOTH session cookies (web) AND Bearer tokens (mobile).

### Web Authentication (Session-based)

- Login via NextAuth.js at `/api/auth/signin`
- Session maintained via HTTP-only cookies
- All documented endpoints support session auth

### Mobile Authentication (Bearer tokens)

- Mobile-specific endpoints at `/api/auth/mobile/_*`
- Use JWT Bearer tokens: `Authorization: Bearer {token}`
- All endpoints support both auth methods
- See \"Mobile Authentication\" tag for mobile-specific endpoints
