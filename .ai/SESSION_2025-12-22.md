## Technical Decisions

### Why TypeScript over Python?
**Decision**: Use Next.js/TypeScript stack

**Reasons**:
1. Single language across frontend and backend
2. Unified codebase (one deployment)
3. Next.js API routes = no separate backend needed
4. Better for AI-assisted development
5. Simpler AWS deployment
6. Type safety across full stack

**Trade-offs**:
- Python would be better for heavy data processing
- But our use case (web app + streaming) suits Node.js well

### Why PostgreSQL on Port 5433?
**Problem**: User has local PostgreSQL on default port 5432

**Solution**: Run Docker PostgreSQL on port 5433

**Benefits**:
- No conflict with local instance
- Can use both databases simultaneously
- Clean separation of concerns

### Database Design Decisions
1. **Full metadata JSON**: Store complete Libation JSON in `metadata` field
   - Allows access to any field without re-import
   - Backup/reference for fields we haven't extracted
   
2. **Hierarchical categories**: Parent/child relationships
   - Supports complex category trees
   - Only leaf categories linked to books

3. **Series sequencing**: Store as string (not integer)
   - Handles "1.5", "Prequel", etc.
   - More flexible for various numbering schemes

4. **User features planned**: Progress tracking and custom lists
   - Ready for iOS app development
   - Supports playback position sync

## Issues Encountered & Solutions

### Issue 1: Prisma Migration Permission Errors
**Error**: `P1010: User postgres was denied access on the database book_vault.public`

**Attempted Solutions**:
1. Granted schema permissions ❌
2. Created shadow database ❌
3. Used different PostgreSQL user ❌
4. Tried `prisma db push` instead of migrate ❌

**Root Cause**: Prisma connecting to LOCAL PostgreSQL (port 5432) instead of Docker (also 5432)

**Final Solution**: 
- Changed Docker port to 5433
- Updated DATABASE_URL to use port 5433
- Migration succeeded immediately ✅

**Key Learning**: Always check port conflicts when using Docker with databases

### Issue 2: create-next-app Directory Conflict
**Error**: "The directory book_vault contains files that could conflict"

**Solution**: Manual Next.js setup
- Created all config files manually
- More control over setup
- Avoided conflicts with existing documentation

**Benefit**: Better understanding of Next.js structure
