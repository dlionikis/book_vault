## What Was Built

Native iOS app for Book Vault audiobook library with full feature parity to web app (minus User Lists).

### Completed Features

| Phase | Feature            | Key Implementation                                                  |
| ----- | ------------------ | ------------------------------------------------------------------- |
| 1     | Auth & Browsing    | JWT auth, book grid, detail views, TabView navigation               |
| 2     | Audio Playback     | AVPlayer streaming, playback controls, speed control                |
| 3     | Background Audio   | Lock screen controls, MPNowPlayingInfoCenter, interruption handling |
| 4     | Progress Sync      | Auto-save every 10s, cross-platform sync, continue listening        |
| 5     | Chapter Navigation | Chapter list, skip to chapter, current chapter highlighting         |
| 6     | Search & Browse    | Full-text search, browse by author/series/narrator/category         |
| 7     | Offline Downloads  | Background downloads, local storage, download management            |
| 8     | Offline Mode       | Library caching, offline progress queue, network-aware UI           |

### Deferred to Post-Launch

- **User Lists**: Custom playlists, favorites, want-to-listen lists
- **Reason**: Requires backend API development first
- **Priority**: Nice to have, not essential for initial release

## Development Workflow

### Repository Structure

```
book-vault/
├── app/                      # Next.js web app
├── ios/                      # iOS app
│   ├── BookVault.xcodeproj   # Generated by XcodeGen
│   ├── BookVault/
│   │   ├── Views/            # SwiftUI views
│   │   ├── Services/         # API, Audio, Auth services
│   │   └── Generated/Models/ # OpenAPI-generated models
│   └── project.yml           # XcodeGen config
├── docs/api/openapi.yaml     # API contract (source of truth)
└── test-fixtures/            # Shared test data
```

### VS Code + Xcode Workflow

**Option A: Dual IDE** (Traditional)

- VS Code for backend development
- Xcode for iOS development

**Option B: VS Code Primary** (Recommended)

- VS Code for both backend and iOS
- Xcode only for SwiftUI Previews or App Store submission
- See [mobile/vscode-ios-setup.md](mobile/vscode-ios-setup.md)

### API Contract Management

OpenAPI spec is the single source of truth:

1. Update `docs/api/openapi.yaml`
2. Run `npm run api:generate` (generates TypeScript + Swift)
3. Run `cd ios && xcodegen generate` (if new files added)
4. Implement changes
5. Commit atomically

## Common Commands

```bash
# === iOS Development ===

# Generate Swift models from OpenAPI
npm run api:generate:swift

# Regenerate Xcode project (after adding/removing Swift files)
cd ios && xcodegen generate

# Watch for OpenAPI changes (auto-regenerates)
npm run api:watch

# Open Xcode project
open ios/BookVault.xcodeproj

# === Backend for iOS ===

# Start dev server (accessible to iOS Simulator)
npm run dev

# Start with HTTPS (for device testing)
npm run dev:https

# === Testing ===

# Backend tests
npm test
npm run test:contract

# iOS: Run in Xcode (⌘R) or via Sweetpad in VS Code
```

## Maintenance Notes

### When Making API Changes

1. Update OpenAPI spec first (`docs/api/openapi.yaml`)
2. Run `npm run api:generate` to regenerate all types
3. Update backend implementation
4. Update iOS code to use new/changed models
5. Run `cd ios && xcodegen generate` if new Swift files created
6. Test both platforms before committing

### When Adding New Swift Files

```bash
# 1. Create the file
touch ios/BookVault/Views/NewView.swift

# 2. Regenerate Xcode project
cd ios && xcodegen generate

# 3. Build to verify
# In Xcode: ⌘B, or in VS Code: Sweetpad: Build
```

### Troubleshooting

**iOS can't connect to backend:**

- Use `http://localhost:3000` (not 127.0.0.1)
- Ensure backend is running: `curl http://localhost:3000/api/health`

**Swift models out of sync:**

- Run `npm run api:generate:swift`
- Run `cd ios && xcodegen generate`

**Build errors after pulling changes:**

- Run `cd ios && xcodegen generate`
- Clean build: Product → Clean Build Folder in Xcode
