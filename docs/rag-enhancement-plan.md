# RAG Enhancement Plan

**Purpose**: Improve AI assistant's ability to understand and work with the codebase through better documentation and code annotations.

**Timeline**: 4 phases over ~2-3 weeks  
**Priority**: Medium (improves developer experience)

---

## Phase 1: Quick Wins (1-2 hours)

_High impact, low effort foundations_

### 1.1 Create RAG Maintenance Guide

**File**: `docs/rag-maintenance-guide.md`  
**Purpose**: Instructions for AI to self-update documentation when code changes

**Contents**:

- Checklist of what docs to update when adding features
- Trigger phrases to recognize when updates are needed
- Examples of good JSDoc comments
- Component README template
- When to update code-map.md

**Action**: Create this file first (see template below)

### 1.2 Component Inventory

**File**: `components/README.md`

**Content structure**:

```markdown
# Components Index

## Audio & Playback

- **AudioPlayer** - Main audio playback UI with controls
- **PlaybackClient** - Client-side playback state management
- **ChapterList** - Display and navigate book chapters
- ...

## Book Display

- **BookCard** - Single book display with cover and metadata
- **BookGrid** - Grid layout for multiple books
- ...
```

### 1.3 API Routes Index

**File**: `app/api/README.md`

**Content structure**:

```markdown
# API Routes Index

## Books

- `GET /api/books` - List all books with filters
- `GET /api/books/[id]` - Get single book details
- ...

## Playback

- ...
```

## Phase 2: JSDoc Foundation (3-4 hours)

_Add structured comments to most-accessed code_

### 2.1 Core Component JSDoc

Add comprehensive JSDoc to:

- `components/AudioPlayer.tsx`
- `components/BookCard.tsx`
- `components/BookGrid.tsx`
- `components/ContinueListening.tsx`
- `components/Pagination.tsx`

**Template**:

```typescript
/**
 * [One-line description]
 *

 *
 * @param propName - Description
 * @returns Description of rendered output
 *
 * @example
 * <Component prop={value} />
 */
```

Add route-level comments to all files in:

- `app/api/books/`
- `app/api/playback/`
- `app/api/library/`
- `app/api/auth/`

**Template**:

```typescript
/**
 * [METHOD] /api/path
 *
 * [Purpose and behavior]
 *
 * Auth: Required/Optional/Public
 * Request: [Description of expected input]

 *

 * // Usage example
 */
```

Add JSDoc to all interfaces:

```typescript
export interface BookWithProgress {
  /** UUID generated by Prisma */
  id: string;

  /** Book title as imported from Audible metadata */
  title: string;

  /** ISO 8601 timestamp when user added to library */
  addedAt?: string;

  /** Listening progress 0-100, null if never started */
  progressPercentage?: number | null;

  // ... etc
}
```

## Success Metrics

After completion, AI should be able to:

1. Find the right component/file in 1-2 searches (vs 3-5 currently)
2. Understand data flow without reading multiple files
3. Know which patterns to follow when adding features
4. Update documentation automatically when instructed
